# Code of Conduct

## Our Standard

`PSDN-AI/SONAR-OSS` aims to be a respectful, practical, and inclusive project space.

Participants are expected to:

- communicate professionally and respectfully
- focus feedback on the work, not the person
- welcome contributors with different backgrounds and experience levels
- assume good intent while still being clear about technical concerns

Unacceptable behavior includes:

- harassment, hate speech, or discrimination
- personal attacks, insults, or sustained hostility
- sexualized language or unwanted sexual attention
- publishing someone else's private information without permission
- repeated bad-faith disruption of project discussion or review

## Scope

This code of conduct applies in project spaces, including issues, pull requests, discussions, and other
maintainer-managed channels related to this repository.

## Reporting

If you experience or witness behavior that violates this code, report it through a private GitHub channel
when possible. If no private reporting path is available, contact the repository owner through GitHub and
request a private follow-up.

## Enforcement

Maintainers may edit, remove, or moderate content and may limit participation by anyone whose behavior
violates this code of conduct. Enforcement should be proportional to the impact and pattern of behavior.
